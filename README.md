# Resume Builder Website

A responsive Resume Builder Website developed using HTML, CSS, and JavaScript to help users create professional resumes easily.

## Features
- User-friendly interface
- Resume information input fields
- Multiple resume templates
- PDF download functionality
- Responsive website design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- html2pdf.js

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
